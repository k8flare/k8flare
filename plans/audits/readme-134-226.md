### Claim 3: Ability to revoke a token (135)

**Verdict: PARTIAL**

README says "revoke". Code:
- `packages/cli/token.go:26-35`: verb list is `list`, `create`, `delete`. No `revoke`.
- `packages/cli/token.go:107-110`: if `tokenID` contains `.`, it cuts at the first dot; K10 token `K10<hash>::<id>.<secret>` becomes `K10<hash>::<id>` and returns 404.
- `packages/cli/cli_test.go:152-163,254`: tests use only bare `id.secret` form.

The verb `delete` exists, but does not accept the printed K10 token string. Expected behavior (delete `K10<hash>::<id>.<secret>`) is not delivered.
